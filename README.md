# DEPORTIVASA — Automatización

Sistema de automatización para DEPORTIVASA (organización de torneos de fútbol).

Estado: repositorio inicial. La Fase 1 (lectura de Drive, selección de fotos y resumen por mail, sin publicar) se agrega a continuación.

Reglas del proyecto:
- Los DNI y planillas de jugadores nunca se guardan en este repositorio.
- Las claves y credenciales nunca se guardan en el código: van en los Secrets del repositorio.
